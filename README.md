# سامانه مدیریت اطلاعات دستگاه‌های سخت‌افزاری

سامانه‌ای تحت گرافیک (GUI) برای ثبت و مدیریت اطلاعات سخت‌افزاری و نرم‌افزاری دستگاه‌های کامپیوتری. این ابزار برای مدیران سیستم و شبکه طراحی شده است تا بتوانند اطلاعات کاملی از دستگاه‌های موجود را در یک دیتابیس مرکزی نگه‌داری کنند.

## 🧩 ویژگی‌ها

- ثبت اطلاعات کامل دستگاه (کیس، مانیتور، کیبورد، ماوس، چاپگر و ...)
- ثبت مدل و ظاهر دستگاه‌ها
- ثبت اطلاعات شبکه (IPv4، IPv6، MAC)
- ثبت اطلاعات سیستم (نام کامپیوتر، سیستم عامل، CPU، RAM، GPU، فضای دیسک)
- ثبت اطلاعات تحویل (تاریخ، تحویل‌گیرنده، شماره داخلی)
- خروجی اکسل با رمز محافظت شده
- دیتابیس SQLite سبک و بدون نیاز به سرور


## 🛠️ نصب و اجرا

### پیش‌نیازها

- Python 3.8 یا بالاتر
- کتابخانه‌های زیر:
  - `tkinter`
  - `sqlite3`
  - `psutil`
  - `openpyxl`

### نصب کتابخانه‌ها

```bash
pip install psutil openpyxl sqlite3 tkinter
```
